# 全形态资源与执行器

探原通过 DSH 提交、跟踪和取消研究、采集与订阅任务。研究助手先从有限样本提取任务目标、来源、规则和需要确认的事项。工作进程校验任务单后批量执行。站点结构或权限发生变化时重新抽样，保留已完成结果和失败原因。覆盖度按目标站点和任务样本测量。

## 十类资源

| 资源 | 获取与处理 | 验收 |
|---|---|---|
| 网页与结构化数据 | 官方 API、Feed、Sitemap 或 HTTP 优先，动态页面使用已验证的浏览器路径 | 结果有原文定位，日期、来源和适用版本可核对 |
| 连载文本 | 小样本验证目录和正文规则，再按章增量采集 | 章节顺序、去重、缺章和失败项可复查 |
| 点播视频 | yt-dlp 优先。授权页面可用 Playwright 观察媒体加载。对允许获取的流交由 N_m3u8DL-RE 或 FFmpeg | 分开记录页面识别、流可取用和完整交付，字幕带时间戳 |
| 软件、游戏与归档 | 从发行页读取版本、分卷和镜像，按条件选择 aria2 或托管站适配。可信校验后隔离解压 | 分卷齐全、校验与版本对应。可执行文件仅交付。跨镜像续传须先核对内容身份 |
| 音乐与歌单 | 导入授权歌单，用 ISRC、时长和版本匹配。按需用参考音频指纹辅助核验，保留源编码并补标签 | 核对录音版本和发行曲序，记录待确认、仅元数据、失败。歌词须与录音版本匹配 |
| 图集、漫画与视觉素材 | 对受支持且允许下载的来源评估 gallery-dl。记录画集、章节、页序、返回的尺寸与来源。CBZ/PDF 作为可选导出 | 核对缺页、重复与顺序。可确认时标注原图或缩略图。访问受限或无法获取原图时单独记录。可读页面的授权渲染快照与原图分开标注。[gallery-dl](https://github.com/mikf/gallery-dl) |
| 学术论文、电子书和数据集 | arXiv/Crossref 发现与核对文献。优先授权的源文件、XML 或 EPUB。PDF 比较 Docling/MinerU。数据集使用官方客户端或 API，固定 revision 并先核对文件清单、许可与配额 | 区分书目、摘要、原始全文和解析产物。公式、跨页表格与多栏阅读顺序抽查。数据集按实际字节校验完整性。[Docling](https://docling-project.github.io/docling/) · [Hugging Face 下载接口](https://huggingface.co/docs/huggingface_hub/guides/download) |
| 直播与实时事件 | Streamlink 与 FFmpeg 面向获准的直播录制。WebSocket、SSE 或轮询接收已授权的数据。按时间或大小分段 | 按时间窗报告覆盖、间断与重连。按源事件 ID 或序列去重。源不支持历史回放时，明确标注空窗。[Streamlink](https://streamlink.github.io/) |
| 播客与长音频 | RSS enclosure 获取允许使用的附件。优先已有文稿，再用 faster-whisper/FunASR 转写。说话人切分作为独立可选步骤 | 保存时间戳和输入音频版本。说话人标签表示分组，真实姓名需独立证据。以中英文片段核验转写及定位。[FunASR](https://github.com/modelscope/FunASR) |
| IM 与协作空间 | 使用平台授权的 API、MCP 或导出文件。按空间和消息游标同步，保留线程、文档块与编辑版本。适配 Telegram、Discord、飞书、Notion 等实际可授权范围 | 引用能定位到消息或文档块，处理更新、删除和授权撤销。私有内容按身份隔离，外发需单独授权。[Notion 分页块接口](https://developers.notion.com/reference/get-block-children) · [Discord Gateway](https://docs.discord.com/developers/events/gateway) |

## 七个能力模块

1. **发现与协议**处理搜索、官方 API、Feed、Sitemap 和已验证的站点工具。WebMCP/NLWeb 继续按实验适配推进。
2. **网页与交互**覆盖 HTTP/正文提取、动态页面和授权交互。Playwright 做基线，Lightpanda 做只读 JS 对照。
3. **文档与结构**处理原生文本、版面、公式、表格和 OCR。
4. **音视频**复用点播、直播、音乐归档、字幕和转写子流程。ASR 和说话人切分可分别启用。
5. **图集**提供有顺序的图片下载、元数据、缺页校验和可选导出。
6. **大文件**管下载、校验、分卷和隔离解压。P2P 单独启用，并明确可能对外上传。
7. **项目与协作连接器**读取代码仓、消息、线程和文档块。各平台拥有独立的认证和增量语义。

这些是能力边界。协议发现可为多个模块提供输入，获取、解包和解析可用同一任务串联，具体组件可替换。

## 调度契约扩展

| 执行类型 | 进度与恢复 |
|---|---|
| 有限读取 `snapshot` | 在预算内返回证据和 Artifact，可记录失败项 |
| 有限采集 `batch` | 持久保存条目 ID、成功文件与校验状态。恢复时跳过已验证项，未知结果先核对 |
| 有界订阅 `subscription` | 由用户显式启动。使用结束时间或保留窗口，按游标或分段检查点恢复，记录不可补采的时间段 |

执行器声明支持的能力、访问范围、输入和输出限制、取消方式与真实恢复能力。任务单只含可验证的来源、预算、预期产物及凭据引用。网页或模型生成的说明不能直接成为下载命令、文件路径或权限。访问控制、验证码和受保护内容返回可诊断状态。外部进程运行在隔离范围内，统一控制网络、时长、并发和磁盘，取消后验证资源已释放。

结果分层保存来源记录、原始文件、解析产物及可引用锚点，附上抓取时间、校验和、解析版本和截断或缺失信息。长驻订阅和账号同步分别设置保留周期，默认关闭通知。

## 施工顺序

- **v0.1**完成 DSH 研究闭环及共享任务、预算和 Artifact 契约。用一个可控 HTTPS 文件验证通用下载、取消、续传和校验。
- **G7**按能力逐个扩展。先做有限任务，包括图库样本、文档与数据集、点播、播客和歌单。随后做直播分段与协作空间增量同步，分别验证断流、缺口、撤销授权和资源回收。
- **G8**在任务契约稳定后接入 MCP/CLI。各模块按来源、实际环境与任务样本公开测得的覆盖率。单独记录可访问、可识别、可解析和完整交付。
