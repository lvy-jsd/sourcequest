# 探原的高级获取路线

本设计把协议、网页交互、多模态证据和持续监测纳入同一体系。阶段范围按工程成熟度和实际验证决定。DSH 原生插件仍是首发入口。

| 能力 | 采用方式 | 验收依据 |
|---|---|---|
| 官方 API、RSS/Atom、结构化元数据 | 优先使用已配置的官方接口。发布者 Feed 和 JSON-LD 可用于发现来源和提取字段。 | 保留站点、发布时间、版本和证据类型。自述元数据与正文证据分别标注。 |
| WebMCP、NLWeb | WebMCP 作为受控浏览器实验适配，明确支持的宿主与站点。NLWeb 仅查询已配置的站点端点。 | WebMCP 仍处 Chromium Early Preview，站点须自行提供工具。将工具描述视为站点数据，调用以本地授权为准。NLWeb 返回的答案保留原文核验路径。[Chrome WebMCP](https://developer.chrome.com/docs/modern-web-guidance/guides/webmcp/webmcp) · [NLWeb 参考实现](https://github.com/nlweb-ai/NLWeb) |
| 浏览器读取与交互 | Playwright 作为基线。优先使用精简无障碍树或定位器，遇到图形交互再使用截图。Lightpanda 进入只读 JS 渲染对照实验。 | 检查翻页和筛选的实际结果，导航后重新定位。Lightpanda 无图形渲染引擎，其兼容性、资源收益与耗时按同题测量。[Playwright ARIA 快照](https://playwright.dev/docs/aria-snapshots) · [Lightpanda 架构](https://github.com/lightpanda-io/docs/blob/main/src/content/core-concepts/architecture-overview.mdx) |
| 多模态原文 | PDF 先做原生文本与表格提取，扫描件按需 OCR。音视频先用合法可读字幕，再评估本地转写。网页图表优先读公开数据或导出文件。 | 每条证据保留页码、表格坐标、时间戳或图像位置。视觉读数和转写标为估读或推断，保留原图及原音定位。[Docling](https://docling-project.github.io/docling/) · [Whisper](https://github.com/openai/whisper) |
| 来源核验 | 跟踪引用链，按任务优先核对官方公告、论文原件、原始数据和代码版本。区分转载、引用与独立证据。 | 输出原文定位、版本和条件。营销、低质量和疑似生成内容的标签只作排序线索，冲突结论保留异议与缺口。 |
| 快照与语义差分 | 用户主动订阅后，保存任务范围、上次快照和关注字段。先用条件请求、散列与结构差分，再用语义判断过滤噪声。 | 以旧值、新值、前后证据和变更时间交付。相同事件去重，通知由用户设置，失败和无法核实的变化单独显示。 |

## 获取路线与交互边界

获取采用能力驱动的选择。官方接口或站点显式提供的结构化能力、静态 HTTP、专项解析、轻量 JS 执行和完整浏览器共享同一预算。根据内容类型、权限和执行器能力选择入口，动态渲染优先使用已验收的本地路径。授权的第三方 Reader 是可选路线，适用范围、费用和数据外发要求独立配置。

登录、验证码、付费墙和访问拒绝进入明确的停止或人工接管状态。浏览器通过用户授权的专用会话访问站点，并限定会话、站点、操作和有效期。反检测浏览器、挑战解锁及代理轮换不作为这些状态的升级路径。

交互默认限于研究范围内的导航、筛选和读取。外部提交、上传或其他改变状态的操作需要明确的目标与授权。页面字段和 WebMCP 描述不授予权限。读到外部文本后也不能因此放宽工具范围或发出新动作。使用受限工具、出站策略、隔离会话、结构化参数校验和执行前检查。清洗隐藏元素与辅助模型审查仅作为额外检查。

点播、下载、图集、长音频、流订阅与协作空间的具体执行和验收见[全形态资源与执行器](RESOURCE_EXECUTORS.md)。

## 实施顺序

1. **v0.1 首发**完成 Provider 接入和原有管理器兼容、逐查询状态、公开 HTTP 读取、输出预算、会话受权 Artifact 和可复核引用。用外部内容影响操作的回归场景检查权限边界。
2. **v0.2 扩展**接入官方 API/Feed、PDF 与表格定位、浏览器只读交互和一次性快照对比。对比 Lightpanda 与 Playwright 的正文完整率、成功率、内存和耗时，再决定是否启用轻量执行器。
3. **后续扩展**评估 WebMCP/NLWeb、授权浏览器接管、音视频和图表定位、用户主动订阅与语义差分。先验证结果、权限、来源和任务恢复，再对外承诺支持范围。

以正文完整率、结构提取准确率、原文支撑率、任务成功率、变化误报漏报率、送入模型的 token、p50/p95 时延和费用评估。按执行器和输入类型分别报告。未经对照测试，几十毫秒、前 1% 和准确率都不作为发布承诺。
