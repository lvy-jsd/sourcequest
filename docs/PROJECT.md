# 项目范围

## 目标

首先面向个人高标准研究场景，追求可核验的研究深度、原文支撑、任务完成度与可复现性。企业级研究质量是目标，尚未取得相应评测成绩。

首发为 DSH 原生插件，用户继续在自己的会话与预设中使用；后续为其他客户端提供适配。

## 首发交付

- 一个标准 DSH 插件包和原生设置入口。
- 统一的研究请求、任务状态、证据与结果契约。
- 自动选择与手动覆盖并存。
- 普通搜索、已知链接读取及一组明确验证过的专题适配。
- 短任务直接结果、长任务进度与持久检查点。
- 证据定位、失败/缺口报告及初始评测集。

## 质量标准

关键事实应关联真实读取的证据；无法支撑时说明推断或未知。研究预算耗尽时保留未完成问题，输出部分结果。完整性哈希和引用定位不单独证明来源或结论为真。

评测分别观察任务覆盖、事实正确性、引用支撑、时效、延迟、模型消耗和失败恢复。模型自动评分需要参考证据和必要的人工抽查。

## 当前边界

尚未实现插件、发布包或验证宿主兼容性。连接器、浏览器和证据协议的候选需经过独立适配与对照测试，不能把路线图视作已支持列表。

首期不要求多人权限系统、分布式集群或另一套聊天应用；实际需求出现后再扩展。来源权限、数据覆盖、模型能力和预算始终是质量约束。
